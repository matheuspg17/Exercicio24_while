# Resolução Exercicio24_while

## Descrição do problema
Escreva um programa em Java que mostre todos os números pares entre 13 e
23 usando do..while.

## Como Funciona
1. O algoritmo declara e inicializa uma variável contadora `i` com o valor inicial igual a 1 (`int i = 1`).
2. A estrutura de repetição `while (i <= 10)` avalia a condição antes de cada execução.
3. Dentro do laço, a instrução `System.out.println(i)` imprime o valor atual da variável na tela.
4. Logo após a impressão, a variável de controle sofre um incremento unitário manual (`i++`) para avançar na sequência e evitar um loop infinito.
